## Submitted plan shape

```
AdaptiveDatafusionExec
  SortExec: [s_name ASC]
    Projection: [s_name, s_address]
      DynamicJoinSelectionExec plan_id=3 LeftSemi(s_suppkey, ps_suppkey) repartitioned=false
        HashJoinExec CollectLeft Inner(n_nationkey, s_nationkey)   ← nation broadcast
          FilterExec n_name = CANADA
            DataSourceExec nation
          DataSourceExec supplier
        Projection: [ps_suppkey]
          DynamicJoinSelectionExec plan_id=2 Inner(ps_partkey=l_partkey, ps_suppkey=l_suppkey)
                                   filter=ps_availqty > 0.5·sum(l_quantity) repartitioned=false
            HashJoinExec CollectLeft RightSemi(p_partkey, ps_partkey)   ← filtered part broadcast
              ExchangeExec broadcast plan_id=4 stage_id=0
                FilterExec p_name LIKE forest%
                  DataSourceExec part
              DataSourceExec partsupp
            Projection: [0.5·sum, l_partkey, l_suppkey]
              AggregateExec FinalPartitioned gby=(l_partkey, l_suppkey) sum(l_quantity)
                ExchangeExec Hash([l_partkey, l_suppkey], 16) plan_id=5 stage_id=1   ← SPILLER
                  AggregateExec Partial gby=(l_partkey, l_suppkey) sum(l_quantity)
                    FilterExec l_shipdate in [1994-01-01, 1995-01-01)
                      DataSourceExec lineitem
```

At SF10 the filtered `part` (matching `LIKE 'forest%'`) is small enough
that AQE chooses `CollectLeft` (broadcast) for the `partsupp ⋈ part`
join, so only one Hash-exchange stage exists — the `lineitem`
partial-agg → hash shuffle for the correlated `sum(l_quantity)`
aggregate. This is the single stage that spills.

## Goal

Drive `spill events → 0` by replacing the `Hash([l_partkey, l_suppkey], 16)`
exchange with a post-shuffle range-filter pattern: stage N ships TDigest
sketches back to the scheduler via `#2175`, scheduler picks
globally-optimal cuts, and emits K stage N+1 tasks with per-task literal
`FilterExec` predicates covering disjoint ranges — no cross-partition
buffering in the shuffle writer.
